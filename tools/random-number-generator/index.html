About Random Number Generator

Generate truly random numbers in any range you choose — from a single dice roll to thousands of unique values. Numbers come from the Web Crypto API (CSPRNG) with rejection sampling, so every value is as fair as a browser can produce.

How to use Random Number Generator

  1. Set the minimum, maximum and how many numbers you need.
  2. Turn on "Unique" for distinct values, or pick decimal places for non-integers.
  3. Press Roll — then copy the list or download it as a .txt file.

Supported formats & options

  • Input: range, count, unique & decimals options
  • Output: a list of random numbers (copy or .txt download)

Common use cases

  • Fair dice rolls and classroom games
  • Drawing sample numbers for testing and QA
  • Picking random seats, slots or giveaway numbers

Frequently asked questions

Are the numbers actually random?

Yes. The tool uses the browser's Cryptographically Secure PRNG (the same source as encryption keys) with rejection sampling, so results have no modulo bias.

Can I get the same number twice?

Only if you turn off "Unique". With Unique on, each number appears at most once per roll.

What is the largest range supported?

Ranges up to roughly 4.29 billion values, which covers virtually any everyday use.
