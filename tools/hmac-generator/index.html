About HMAC Generator

Generate an HMAC (keyed hash) of any text or file using SHA-1, SHA-256, SHA-384 or SHA-512, and compare it against an expected signature. Computed with Web Crypto — the key never leaves your device.

How to use HMAC Generator

  1. Paste a message or drop a file.
  2. Enter your key and choose the algorithm.
  3. Click Compute — then optionally paste an expected signature to verify a match.

Supported formats & options

  • Input: text or file + key + algorithm
  • Output: HMAC hex signature

Common use cases

  • Verifying message integrity between systems that share a secret
  • Signing API requests with a shared key
  • Checking that a file hasn't been tampered with

Frequently asked questions

What is HMAC?

A keyed hash: a signature computed from a message and a shared key. The same message and key always give the same signature; a different key gives a completely different one.

Which algorithms are supported?

HMAC-SHA-1, HMAC-SHA-256, HMAC-SHA-384 and HMAC-SHA-512.

Is the key uploaded?

No — everything is computed locally in your browser with Web Crypto.
