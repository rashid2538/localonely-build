About Color Converter

Type any color — #aabbcc, rgb(10,20,30), hsl(200, 50%, 40%), hsv() or cmyk() — and see it converted to every format at once, plus its nearest CSS color name. All conversion happens in your browser.

How to use Color Converter

  1. Type or paste a color in any supported format.
  2. Watch every other format update instantly with a live swatch.
  3. Copy the format you need with a single click.

Supported formats & options

  • Input: HEX, rgb(), hsl(), hsv(), cmyk() or a CSS color name
  • Output: HEX, RGB, HSL, HSV, CMYK and nearest name

Common use cases

  • Turning a HEX value from a design tool into CSS rgb() or hsl()
  • Matching print colors by converting RGB to CMYK
  • Finding a friendly name for a color you picked

Frequently asked questions

How do I convert HEX to RGB?

Type the hex value (e.g. #ff0000) and the RGB row shows rgb(255, 0, 0) automatically — no button to press.

Is my color data sent anywhere?

No. Conversion runs entirely in your browser; nothing is uploaded or stored.

Can I convert a CSS color name?

Yes — type a name like "rebeccapurple" or "tomato" and it resolves to its exact value, shown in every format.
