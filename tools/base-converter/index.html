About Base Converter

Convert any number between base 2 and base 36 — binary, octal, decimal, hexadecimal and anything in between. Conversion is done with BigInt, so values thousands of digits long stay exact.

How to use Base Converter

  1. Type the number (digits 0–9 and letters A–Z).
  2. Choose its base and the base you want to convert to.
  3. Read the result, and see the common bases side by side.

Supported formats & options

  • Input: number string + from/to base (2–36)
  • Output: converted value + binary/octal/decimal/hex table

Common use cases

  • Translating hex colors, memory addresses or opcodes to decimal
  • Explaining binary and hex to students
  • Working with base-36 IDs and compact encodings

Frequently asked questions

Which bases are supported?

Any base from 2 to 36. Digits 0–9 stand for values 0–9 and letters A–Z for 10–35.

Can it handle very large numbers?

Yes — all math uses BigInt, so there is no precision loss, even for numbers far beyond 64-bit range.

Does it accept a negative number?

Yes — a leading minus sign is preserved through the conversion.
