About File Type Detector

Drop in any file and find out what it really is by reading its magic bytes — the signature in the first few bytes — rather than trusting the filename extension. The detector covers images, documents, office files, archives, audio, video, fonts, executables and source text, and even disambiguates ZIP-based formats like .docx from plain ZIPs.

How to use File Type Detector

  1. Drop a file or click to choose it.
  2. Read the detected type, MIME, extension and size.
  3. Check the dimensions for image formats when available.

Supported formats & options

  • Input: any file
  • Output: detected format, MIME type, extension, size

Common use cases

  • Finding out what a renamed file actually is
  • Checking a file before opening a suspicious download
  • Verifying exported files are really the format they claim

Frequently asked questions

How does magic-byte detection work?

Every file format starts with a recognizable byte signature — PNG always begins 89 50 4E 47, PDF starts %PDF, ZIP starts PK. The tool matches those signatures instead of trusting the filename.

Can it tell a .docx from a .zip?

Yes — both are ZIP containers, so the tool peeks inside and checks for the Word, Excel or PowerPoint content markers to tell them apart.

Is my file uploaded?

No. Only the first few bytes are read, entirely in your browser.

What if nothing matches?

Unknown or heavily compressed binary data is reported honestly as unrecognized rather than guessed.
