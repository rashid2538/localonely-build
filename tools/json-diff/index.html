JSON Diff

Compare two JSON documents and see exactly what changed — added, removed and modified keys with their paths. Free JSON diff tool, 100% in your browser.

🔒 Your files never leave your device

About JSON Diff

Paste two JSON documents and get a structure-aware diff: every key that was added, removed or changed, with a readable path like user.address.city. Object keys are compared regardless of order; arrays by position.

How to use JSON Diff

  1. Paste the left and right JSON documents.
  2. Review the added, removed and changed paths.
  3. Copy or fix the values that differ.

Supported formats & options

  • Input: two JSON documents (text)
  • Output: list of add/remove/change ops with paths

Common use cases

  • Spotting what an API response changed
  • Reviewing config or data migrations
  • Confirming two outputs are identical (a clean diff means no change)

Frequently asked questions

Does key order matter?

No — objects are compared by key name, so {"a":1,"b":2} and {"b":2,"a":1} are identical. Arrays are compared by position.

What counts as changed?

Any value that isn't deeply equal — including type changes like 1 versus "1".

Is my JSON uploaded?

No — the diff runs entirely in your browser.
