CSV Viewer

Preview CSV and TSV files as a clean table with automatic delimiter detection, sticky headers and row/column counts. Free viewer, runs entirely in your browser.

🔒 Your files never leave your device

About CSV Viewer

Open any CSV or TSV file and see it as a proper table — delimiter auto-detected (comma, semicolon or tab), first row treated as a header, sticky column headers while you scroll, and instant row and column counts. Nothing is uploaded.

How to use CSV Viewer

  1. Drop a .csv, .tsv or .txt file.
  2. The delimiter is detected automatically and the table renders.
  3. Scroll the sticky-header table and read the row/column counts.

Supported formats & options

  • Input: CSV/TSV text or file
  • Output: a scrollable table with counts

Common use cases

  • Quickly checking a CSV before importing it somewhere
  • Previewing exported spreadsheet data without Excel
  • Verifying delimiter and quoting in data files

Frequently asked questions

Does it handle quoted fields with commas?

Yes — the RFC-4180 parser handles quoted fields, escaped quotes and embedded newlines, so a comma inside quotes is never treated as a column break.

Which delimiters are detected?

Comma, semicolon and tab — the detector compares their frequency on the first line and picks the winner.

Is my file uploaded?

No. The file is parsed locally in your browser and never transmitted.
