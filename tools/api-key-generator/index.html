About API Key Generator

Generate cryptographically secure API keys and secrets with the format you need: hex, URL-safe base64, alphanumeric, numeric or printable ASCII, with an optional human-readable prefix like sk_live and character grouping for readability. An entropy readout shows the strength of each key.

How to use API Key Generator

  1. Choose a character set and key length.
  2. Add an optional prefix (like sk_live) and grouping separator.
  3. Generate, then copy the keys — they are shown only once.

Supported formats & options

  • Input: charset, length, count, prefix, grouping
  • Output: 1–50 generated keys with entropy readout

Common use cases

  • Creating API keys for web services and SDKs
  • Generating client secrets and webhook tokens
  • Building test data with realistic key formats

Frequently asked questions

Are the keys truly random?

Yes. Keys are drawn from the browser's Web Crypto API with rejection sampling, which removes the modulo bias a naive random would introduce.

What does the entropy number mean?

It estimates the search space in bits — log₂ of the number of possible keys. Roughly 128+ bits is considered strong for a secret.

Can I reuse the same prefix as a real provider?

Yes — prefixes are cosmetic. Use sk_live, pk_test or anything recognizable; the random body after the underscore is what carries the security.

Are my keys stored anywhere?

No. Keys are generated locally and never persisted — copy them before leaving the page.
