Text Encrypt / Decrypt

Encrypt or decrypt any text with a passphrase, using AES-256-GCM + PBKDF2. Runs entirely in your browser — your message never leaves your device.

🔒 Your files never leave your device

About Text Encrypt / Decrypt

Encrypt a message with a passphrase and get a portable encrypted string, or decrypt one back. AES-256-GCM with a PBKDF2-derived key, random salt and IV per message — the ciphertext is authenticated, so a wrong password fails loudly.

How to use Text Encrypt / Decrypt

  1. Type or paste the text, and choose Encrypt or Decrypt.
  2. Enter a passphrase (and confirm it when encrypting).
  3. Copy the encrypted string — the only way back is the same passphrase.

Supported formats & options

  • Input: plain text or an LFTXT1: encrypted string
  • Output: encrypted string or decrypted text

Common use cases

  • Sending private messages over channels you do not trust
  • Storing secrets, API keys or recovery codes locally
  • Protecting notes before pasting them into shared documents

Frequently asked questions

Is the encryption real?

Yes — AES-256-GCM with a key derived from your passphrase via PBKDF2 (150,000 iterations). Each message gets a random salt and IV. Nothing is uploaded.

Can I decrypt it later?

Yes — switch to Decrypt, paste the LFTXT1: string and enter the passphrase. Wrong passphrase or tampered text fails loudly rather than decrypting to garbage.

What if I forget the passphrase?

The encryption is deliberately irreversible without it — there is no recovery. Use a passphrase you will remember or store it safely.
