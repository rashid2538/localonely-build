About HTML Formatter

Pretty-print messy HTML into clearly indented markup, or minify it for smaller files — with validation that catches mismatched and unclosed tags. Void elements and the contents of script, style, pre and textarea are left exactly as they are.

How to use HTML Formatter

  1. Paste your HTML into the input box.
  2. Choose Format or Minify, and pick a 2- or 4-space indent.
  3. Copy the result or download it as an .html file.

Supported formats & options

  • Input: HTML source
  • Output: formatted or minified HTML

Common use cases

  • Cleaning up HTML exported from WYSIWYG editors
  • Minifying template snippets before shipping
  • Checking for mismatched tags before deploying a page

Frequently asked questions

Does it handle script and style content?

Yes — the contents of <script>, <style>, <pre> and <textarea> are kept verbatim, so your JavaScript and CSS are never reindented or corrupted.

Does formatting change my markup?

Only whitespace. Tag and attribute text is preserved, void elements (br, img, input…) stay on one line, and errors are reported instead of silently fixed.

Is my HTML uploaded anywhere?

No — everything is formatted locally in your browser.
