About JSON ↔ CSV

Convert JSON to CSV or CSV to JSON without losing fidelity. Nested objects flatten to dotted keys (a.b.c) and unflatten on the way back; JSONL, single objects and arrays of arrays are all accepted, and the CSV delimiter is auto-detected.

How to use JSON ↔ CSV

  1. Pick the direction: JSON → CSV or CSV → JSON.
  2. Paste or upload your data (or pick a delimiter for CSV input).
  3. Copy the result or download it as .csv or .json.

Supported formats & options

  • Input: JSON (array / object / JSONL) or CSV
  • Output: CSV or pretty-printed JSON

Common use cases

  • Moving data between APIs and spreadsheets
  • Exporting query results for Excel or Google Sheets
  • Converting CSVs back to JSON for code and configs

Frequently asked questions

Does it handle nested JSON objects?

Yes — nested objects are flattened to dotted keys (like user.name) in the CSV, and dotted headers are unflattened back to nested objects on the CSV → JSON side.

What CSV delimiter does it use?

For CSV → JSON it auto-detects comma, semicolon or tab from the first line; you can also choose explicitly. Quoted fields, embedded commas and CRLF line endings are handled.

Is my data uploaded?

No — the conversion runs entirely in your browser.
