About CSS Formatter

Clean up messy stylesheets or shrink them for production. A small tokenizer validates balance (braces, strings, comments) then pretty-prints with your indentation, or minifies while keeping /*! license comments.

How to use CSS Formatter

  1. Paste your CSS into the input box.
  2. Choose Pretty-print or Minify (and optionally sort properties A–Z).
  3. Copy the output or download it as a .css file.

Supported formats & options

  • Input: CSS text
  • Output: formatted or minified CSS

Common use cases

  • Reading and debugging third-party or generated stylesheets
  • Minifying CSS before shipping to production
  • Enforcing a consistent property order across files

Frequently asked questions

Does it fix invalid CSS?

It validates structure — unbalanced braces, unclosed comments or strings are reported, not silently repaired.

Does minifying remove comments?

Yes, except /*! license comments, which are preserved for copyright notices.

Does it handle @media and @keyframes?

Yes — nested blocks like @media, @supports and @keyframes steps are indented correctly.
