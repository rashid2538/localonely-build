About WYSIWYG Editor

A full word-processor-style editor that runs entirely in your browser. Type and format text with a familiar toolbar — bold, italic, headings, lists, alignment, colors, links, images and tables — and switch to HTML source, copy the markup, or download the document as a .html file. Because everything happens locally, nothing you type is uploaded.

How to use WYSIWYG Editor

  1. Type or paste your text into the editor, or click Sample for a starter document.
  2. Select text and use the toolbar — paragraph styles, fonts, sizes, bold, colors, alignment, lists, quotes, links, images and tables.
  3. Hit Clear formatting (the eraser) to strip extra styling while keeping structure, or Full screen for a distraction-free canvas.
  4. Copy the HTML or plain text, or download the document as a .html file.

Supported formats & options

  • Input: typed or pasted content (clean or formatted)
  • Output: formatted HTML — copy, plain-text copy or .html download

Common use cases

  • Composing blog posts, emails, letters and reports with formatting
  • Cleaning up text pasted from the web — the eraser strips junk styling
  • Drafting HTML content without hand-writing tags

Frequently asked questions

Is my document uploaded anywhere?

No. The editor is fully client-side — nothing you type, paste or drop is transmitted or stored.

What does Clear formatting do?

It strips character formatting — bold, italic, colors, font tags and inline styles — while keeping your document structure: headings, lists, quotes, tables and links stay put.

Can I edit the HTML directly?

Yes — switch to the HTML button to view and edit the source, then switch back to apply it (unsafe tags and scripts are filtered out).

Does pasting keep formatting?

Pasted content is cleaned of scripts, event handlers and junk attributes; you can tick Paste as plain text to drop formatting entirely.

How do images work?

Images are embedded directly into the document as data URLs, so nothing is uploaded — but keep them small so the page stays fast.
