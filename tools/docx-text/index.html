  • Output: clean HTML or plain text

  • Turning a .docx into web-ready HTML
  • Searching or quoting a document's content

Frequently asked questions

Does it work with legacy .doc files?

No — only Office Open XML .docx files are supported. Older binary .doc files need Word or LibreOffice to be converted first.

Is my document uploaded?

No — the file is parsed entirely in your browser and never leaves your device.
